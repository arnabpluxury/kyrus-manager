# Terms for contributors & redistributors

Kyrus Manager is shared so people can improve their PCs — and improve the project together.

## Short version

- **Use & study** freely for personal / non-commercial work.
- **Change the code?** If you share those changes (or use them commercially), you **must push the updated files as open source** under the same license.
- **Commercial use without open-sourcing your modifications is not allowed.**

Full legal text: see [`LICENSE`](./LICENSE).

## Why

This project replaces tedious Windows system UIs with transparent, local controls. The license keeps that work from being closed up into a paid fork without giving improvements back.
